# Fluent UI


THe `baka-fluent-ui` package represents the Microsoft Fluent UI design system implemented through the `baka-ui` framework.

It distributes of a collection of all the components and styles that are part of the Fluent UI design system.

## Design

The design was created by Microsoft and is available at [Fluent UI](https://fluent2.microsoft.design/). For more information about the design system, please refer to the official documentation.
